# Orphanage Intro Flags

- `FLAG_ORPHANAGE_MARINA_CALLED_PLAYER_DOWNSTAIRS` (`0x242`): Set after the first 2F intro beat where the player reacts to Mrs. Marina calling them downstairs. While this is set and the quest-start flag is not set, Thomas uses his temporary "Mrs. Marina is waiting downstairs" dialogue.
- `FLAG_ORPHANAGE_ENVELOPE_QUEST_STARTED` (`0x25A`): Set when Mrs. Marina gives the player the envelope (`ITEM_LETTER`) on Orphanage 1F. This restores Thomas's normal dialogue and restores Mrs. Marina's normal 1F placement on subsequent room entries.
